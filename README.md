# 案件档案馆 · Case Archive

一个纯静态的案件档案馆网站，用于系统化整理罪案/纪实案件资料，方便快速回忆案件重点。

## 文件结构

```
index.html   入口页面
style.css    档案馆风格样式
app.js       目录 / 详情 / 检索 / 编辑逻辑
cases.js     ★ 全部案件数据（只改这一个文件即可）
```

## 部署到 GitHub Pages

1. 新建一个仓库（如 `case-archive`），把这 4 个文件上传到仓库根目录。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main` / 根目录 `/`。
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

也可以本地直接双击 `index.html` 打开使用。

## 新增案件

打开 `cases.js`，复制现有案件对象，改掉 `id`（不能重复）后填入内容，提交推送即可。文件顶部有完整的字段说明注释。

## 分类与标签

- `category`（分类）：每个案件填什么，目录页左侧就自动出现对应的筛选项和计数，不用改任何代码。新增分类 = 给案件写一个没见过的新分类名。
- `tags`（标签）：自由填写，展示在卷宗上，目录页的检索框也能搜到标签内容。

## 馆内编辑

- 网页右下角「编辑模式」：开启后点击虚线框内的文字即可直接修改，改动自动保存在当前浏览器（localStorage），刷新不丢。
- 「导出 cases.js」：把当前（含修改的）数据下载为 `cases.js`，用它替换仓库里的同名文件并提交，修改就同步到线上。
- 「导入 cases.js」：读取本站导出的 `cases.js`（或同结构的 JSON 数组文件），整体替换当前卷宗数据——可用于换设备迁移或导入他人分享的卷宗。

> 注意：编辑模式的改动只保存在当前设备的浏览器里，不会自动上传；要长期保存或跨设备同步，请用「导出 cases.js」下载文件并提交到仓库。

## 手机端

已适配手机浏览器：目录页自动变为卡片式列表，卷宗页单栏排版，手机直接访问部署后的网址即可。
